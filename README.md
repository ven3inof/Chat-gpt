# Сайт-приглашение (аналог элегантной свадебной страницы)

Этот репозиторий — ваш личный проект сайта. Вы можете менять в нём любой текст, цвета, блоки и логику.

## Что такое репозиторий

Репозиторий (repo) — это папка проекта, которая хранится в GitHub и содержит:
- файлы сайта (`index.html`, `styles.css`, `script.js`);
- историю изменений (кто и что поменял);
- возможность быстро откатиться к предыдущей версии.

## Что уже сделано

В проект добавлен готовый одностраничный шаблон приглашения:
- крупный первый экран;
- дата события и таймер обратного отсчёта;
- блок программы дня;
- блок с dress-code;
- блок подтверждения присутствия (ссылка на форму).

## Как запустить локально

### Вариант 1 (самый простой)
Откройте `index.html` двойным кликом.

### Вариант 2 (через мини-сервер)
```bash
python3 -m http.server 8000
```
Откройте в браузере: `http://localhost:8000`

## Что менять в первую очередь

Откройте `script.js` и измените объект `INVITE_DATA`:
- `title`, `subtitle` — заголовки;
- `eventDate` — дата и время события;
- `location` — место;
- `program` — пункты программы;
- `dressCode` — описание дресс-кода;
- `rsvpLink` — ваша ссылка на форму подтверждения.

## Как выложить сайт на GitHub Pages

### 1) Сначала отправьте файлы в GitHub (иначе там будет пусто)

Откройте терминал в папке проекта и выполните:

```bash
git add .
git commit -m "Добавил сайт-приглашение"
git push -u origin main
```

Если у вас основная ветка называется не `main`, а `master`, используйте:

```bash
git push -u origin master
```

После этого обновите страницу репозитория на GitHub — файлы `index.html`, `styles.css`, `script.js`, `README.md` должны появиться.

### 2) Включите GitHub Pages

1. В GitHub откройте: **Settings → Pages**.
2. В `Build and deployment` выберите:
   - `Source`: **Deploy from a branch**
   - `Branch`: **main** (или ваша ветка), папка `/ (root)`
3. Нажмите **Save**.
4. Через 1–3 минуты GitHub покажет публичную ссылку на ваш сайт.

## Важно про «сайт аналогичный другому»

Можно сделать похожую структуру и стиль, но лучше использовать свои тексты, свои фото и свой визуал, чтобы избежать проблем с авторскими правами.
